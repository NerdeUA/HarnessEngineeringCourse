# ADR-0004: Порівняння офіційного Qdrant MCP з retrieval MCP від ABox

- Статус: розгортання та оцінювання векторного пошуку завершено; наскрізне оцінювання агентів очікує на дійсні LLM-облікові дані
- Дата: 2026-10-02
- Власник рішення: учасник курсу

## Контекст

Лабораторна 4 вимагає розгорнути реліз ABox `feat/llmd-embeddings`, додати офіційний Qdrant MCP, налаштувати `retrieval-agent` і `k8s-agent`, проіндексувати той самий Kubernetes-корпус моделлю `sentence-transformers/all-MiniLM-L6-v2` і дефолтним Qdrant MCP, а результати порівняння зафіксувати в ADR.

У кластері вже був MCP від ABox із локальним endpoint ембедингів Nomic на llama.cpp. Його залишено базовим варіантом, а для офіційного MCP виділено окрему колекцію. Повторно використовувати одну колекцію не можна: жива конфігурація Qdrant показує 768-вимірні базові вектори та 384-вимірні вектори MiniLM.

## Рішення

Залишити два незалежні шляхи ембедингів і пошуку в одному сервісі Qdrant:

| Варіант | Реалізація MCP та інструменти | Ембединг-модель | Колекція |
|---|---|---|---|
| Базовий | ABox `qdrant-mcp`; `vector_store`, `vector_find` | локальний endpoint Nomic через llama.cpp (`llama-cpp-embeddings.llama-cpp:8090`) | `abox-nomic` (768 вимірів) |
| Порівняльний | офіційний `qdrant/mcp-server-qdrant` v0.8.1; `qdrant-store`, `qdrant-find` | `sentence-transformers/all-MiniLM-L6-v2` | `abox-minilm` (384 виміри) |

`retrieval-agent` і `retrieval-agent-official` використовують наявний `default-model-config` (`OpenAI/gpt-4.1-mini`). Джерелом оголошених Kubernetes-маніфестів залишається `k8s-agent`. Системний промпт офіційного агента дозволяє використовувати лише офіційний MCP і `abox-minilm`; результати базової колекції змішувати не можна. До кожного запису додаються метадані `source`, `kind`, `namespace` і `name`.

Початковий official MCP image на worker-вузлі був непридатний: файл Pygments `_mapping.py` повністю складався з нульових байтів, через що імпорт завершувався `SyntaxError`. Зібрано й перевірено новий локальний image з офіційного пакета `mcp-server-qdrant==0.8.1`, після чого завантажено його в kind під тегом `qdrant-mcp-official:0.8.1-rebuilt`. Старий image залишено без змін. MCP-ресурс у кластері тепер використовує новий тег.

## Оцінювання та результат

Через store-інструмент кожного MCP збережено вісім однакових записів про Kubernetes/ABox. Qdrant підтверджує по вісім точок у кожній колекції; базові вектори мають 768 вимірів, MiniLM — 384. Через find-інструмент кожного MCP виконано чотири однакові семантичні запити. На цьому невеликому корпусі:

- Базовий варіант: цільовий документ на першому місці для всіх чотирьох запитів; Hit@1 — 4/4; Hit@3 — 4/4; MRR — 1,00.
- MiniLM: цільовий документ на другому місці для запиту про сервіс Qdrant та офіційний MCP, і на першому місці для запитів про `k8s-agent` і порівняння агентів; Hit@1 — 2/4; Hit@3 — 4/4; MRR — 0,75.

Це результат на рівні векторного пошуку, а не статистично значущий рейтинг моделей. Корпус малий, підібраний вручну й містить семантично схожі описи; його достатньо, щоб перевірити окрему індексацію та роботу інструментів, але недостатньо для загального висновку про перевагу однієї моделі.

Також зроблено спробу A2A-виклику агента. Контролер повернув HTTP 200, але задача завершилася помилкою моделі `401 Unauthorized` / `invalid_api_key`. Обидва retrieval-агенти посилаються на той самий `default-model-config`, тому порівняти відповіді, згенеровані LLM, і вибір інструментів агентом не вдалося. Значення ключа не читалося й не записувалося.

## Наслідки

- Окремі колекції явно розділяють розмірності векторів і не дозволяють змішувати несумісні ембединги.
- Інструменти офіційного MCP та системний промпт retrieval-агента працюють і перевіряються незалежно від LLM-провайдера.
- Відновлений image локальний для цього kind-кластера; його тег не опубліковано в registry. У новому кластері перед створенням MCP-ресурсу потрібно зібрати й завантажити цей image.
- Для завершення agentic/A2A частини потрібен дійсний OpenAI API key. Наявний векторний benchmark із 8 запитів є доказом індексації та порівняння retrieval, але не замінює фінальне агентське оцінювання.
